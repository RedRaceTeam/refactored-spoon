# Piar Bot

Telegram-бот для пиара INDY Leader через Secretary Mode.

## Настройка

1. Зарегистрировать бота у @BotFather
2. Включить Secretary Mode через @BotFather
3. Привязать бота к твинку через Настройки → Telegram Business → Чат-боты

## Деплой на Render

1. Залить код на GitHub
2. Создать Web Service
3. Задать переменные окружения
4. Включить автодеплой

## Переменные

- BOT_TOKEN — токен бота
- GEMINI_API_KEY — ключ Gemini
- WEBHOOK_URL — https://сервис.onrender.com
- PORT — 8000
- ADMIN_ID — твой Telegram ID

## Команды

- /start — панель управления
